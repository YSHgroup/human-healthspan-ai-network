# AI platform

This top-level Python area is intentionally independent from the FastAPI implementation. It defines a future home for:

- **General Platform AI** — public/common knowledge only.
- **Private AI Scientist** — approved researchers and permission-aware scientific retrieval.
- **Organization-Specialized AI** — organization-controlled knowledge and access boundaries.

No model provider, retrieval workflow, or AI answer endpoint is implemented in this foundation. Private research must not be sent to a general-purpose AI path.
